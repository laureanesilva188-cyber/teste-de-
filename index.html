Conhecendo sobre Teste de Software

O que é teste de software?

Teste de software é o processo de verificar se um sistema funciona corretamente, identificando erros antes que ele seja entregue ao usuário. O objetivo é garantir qualidade, segurança e confiabilidade.

Qual a importância de testar?

  • Evita falhas e prejuízos.
  • Melhora a qualidade do sistema.
  • Aumenta a segurança.
  • Garante melhor experiência para o usuário.
  • Reduz custos com correções futuras.

Exemplos de sistemas que falharam

1. Ariane 5 (1996)

O foguete Ariane 5 explodiu cerca de 40 segundos após o lançamento. A causa foi a reutilização de um código do Ariane 4, causando um erro de overflow.

2. Therac-25 (Década de 1980)

O Therac-25 era um equipamento de radioterapia. Falhas no software permitiram doses incorretas de radiação.

3. Knight Capital (2012)

Um erro em uma atualização fez o sistema enviar milhares de ordens incorretas para a bolsa de valores.

4. Healthcare.gov (2013)

O portal apresentou falhas no lançamento, impedindo usuários de realizar cadastros.

5. Cyberpunk 2077 (2020)

O jogo foi lançado com muitos bugs e problemas de desempenho.
